# 避けゲー (Avoid Game) - 赤ちゃんを守れ！

上から降り注ぐ障害物（モアイ、おばけ、メテオ）を避け、赤ちゃんを守り抜くアクションゲームです。<br>

## 🎮 ゲーム概要
プレイヤーは左右移動とダッシュを駆使して、落下物から逃げ続けます。特定の条件を満たすことで「ハードモード」「Veryハードモード」が解放されます。

### 特徴
* **3段階の難易度システム:**
    * **Normal:** 初期モード。
    * **Hard:** Normalでスコアを記録すると解放。敵の出現頻度が上昇。
    * **Very Hard:** Hardクリアで解放。高速で落下する「メテオ」が登場。
* **やり込み要素:**
    * ハイスコアはバイナリ形式でローカルに保存（永続化）され、次回起動時も挑戦可能。
    * X (Twitter) へのスコア投稿機能連携。

## ⚙️ 技術スタック
* **言語:** C++ (C++20規格)
* **フレームワーク:** OpenSiv3D v0.6.14
* **IDE:** Visual Studio 2022

## 💻 技術的なこだわりポイント
1. **シーン管理と状態遷移**
   * `switch(sceneId)` によるステートマシンを構築し、タイトル、プレイ画面、リザルト、ハイスコア画面の遷移を管理。
2. **オブジェクト指向的な設計**
   * プレイヤー(`Player`)、障害物(`Item`)、難易度管理(`Difficulty`)を構造体でカプセル化し、責務を分離。
3. **データの永続化 (Serialization)**
   * `SIV3D_SERIALIZE` マクロと `BinaryWriter/Reader` を使用し、ハイスコアデータをバイナリファイル(`save.bin`)として暗号化・保存・読み込みする機能を実装。
4. **難易度曲線**
   * 単なるランダム生成ではなく、時間経過(`accumulatedTime`)と出現回数(`spawnTimes`)に応じた難易度上昇アルゴリズムを実装。

## 🕹️ 操作方法

| キー | 動作 |
|:---|:---|
| **A / D** | 左移動 / 右移動 |
| **LShift** | ダッシュ |
| **Space** | ゲームスタート / リトライ / 次へ |
| **ESC** | タイトルに戻る |
| **Q** | タイトルでハイスコア確認 / 戻る |
| **R** | クイックリトライ |
| **Delete + 0** | セーブデータの削除（ハイスコア画面） |

## 📦 インストールと実行方法
